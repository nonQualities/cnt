NOTES ON APPROACH:

Number theory is not developed here mathematically from a proof-heavy method, although, this repo might still contain many or some proofs, dependent on the context. More importance would be given in the algorithmic development of number theory, eventually culminating in topics such as Eliptic Curves, RSA etc. I would use severely, a software which at this point might seem a bit obsolete, in view of recent developments in SAGE, LEAN etc called GP/PARI [https://pari.math.u-bordeaux.fr/]

Languages I plan to use would be thus:

> C / C++
> Julia / Python
> Haskell
